# Spatial Design Reference

## Core Spacing Rhythm
- Use a small, consistent spacing scale (for example: 4, 8, 12, 16, 24, 32, 48).
- Keep related controls tight (8-12px).
- Separate major groups more generously (24-48px).

## Layout Principles
- Prefer Flexbox for one-dimensional alignment patterns.
- Use Grid for true two-dimensional layouts or dashboard structures.
- Avoid repeating identical card blocks everywhere; mix emphasis and density.

## Responsive Behavior
- Prioritize mobile-first structure before adding larger breakpoints.
- Keep primary actions reachable on small screens.
- Convert sidebars to chips, tabs, or horizontal nav on narrow viewports.

## Hierarchy and Readability
- Use spacing first for hierarchy, then color/weight as reinforcement.
- Keep scan paths predictable: title, status, action.
- Ensure text contrast remains readable on any tinted surface.
