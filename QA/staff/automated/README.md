# Staff Automated Suite Blueprint

## Scope

Automate high-risk staff flows first:

1. Request status transitions.
2. Queue serving and completion.
3. Medicine availability updates.
4. Staff notification visibility.

## Spec Naming

- staff-process-requests.spec.ts
- staff-queue.spec.ts
- staff-medicines.spec.ts
- staff-notifications.spec.ts

## Mandatory Assertions

- UI state correctness.
- API response contract correctness.
- DB side-effect correctness.
