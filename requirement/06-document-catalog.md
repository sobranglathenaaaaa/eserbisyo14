# Document Catalog

The system must support the following request catalog and display fee logic clearly in the UI.

## Barangay Certification

- School Requirement: Free
- Indigency / Financial / Medical / Educational Assistance: Free
- PWD / Senior Citizen Application: Free
- Health Card Application: Free
- Death Certification: Free
- Employment: Php 100.00
- Police / NBI / Court Clearance: Php 100.00
- Passport / Postal / Visa Applications: Php 100.00
- Visa Extension / Overseas Employment: Php 100.00
- Certificate of No Operation of Business: Php 200.00
- Other purposes not listed above: Php 200.00

## Transient Employees Or Worker Certification

- Household Employees: Php 100.00
- Company Employees: Php 100.00
- Construction Workers: Php 100.00
- Other Transient Workers: Php 100.00

## Lupon Ng Mga Tagapamayapa Fees

- Lupon Filing Fee: Php 100.00
- Certificate to File Action: Php 300.00

## Business Clearances

- Capital not exceeding Php 20,000.00: Php 500.00
- Capital above Php 20,000.00 up to Php 200,000.00: Php 1,000.00
- Capital exceeding Php 200,000.00: Php 1,500.00

## Construction Clearances

- New Structure: minimum Php 1,000.00 or Php 10.00 per square meter, whichever is higher
- Occupancy, Single Detached: Php 1,000.00
- Occupancy, Apartment per unit: Php 1,000.00
- Occupancy, Townhouse per unit: Php 1,200.00
- Occupancy, Condominium per unit: Php 1,500.00
- Renovation without Expansion, Single Detached: Php 1,000.00
- Renovation without Expansion, Apartment per unit: Php 1,000.00
- Renovation without Expansion, Townhouse per unit: Php 1,200.00
- Renovation without Expansion, Condominium per unit: Php 1,500.00
- Expansion Only: minimum Php 1,000.00 or Php 10.00 per square meter, whichever is higher
- Renovation with Expansion: combined fee based on renovation plus expansion rules
- Fencing: Php 1,000.00
- Installation of Electric or Communication Post: Php 1,000.00 per post
- Manila Water Excavation: Php 1,000.00 per excavation point
- Drainage Works, one side: Php 1,000.00
- Drainage Works, two sides: Php 2,000.00
- Other Excavation: Php 1,000.00 per excavation point
- Demolition, Single Detached: Php 1,000.00
- Demolition, Apartment per unit: Php 1,000.00
- Demolition, Townhouse per unit: Php 1,200.00
- Demolition, Condominium per unit: Php 1,500.00

## Delivery And Hauling Clearance

- Concrete mixer per trip: Php 300.00
- Hauling of debris using 10-wheeler and up: Php 1,000.00 per truck per day
- Delivery of filling materials using 10-wheeler and up: Php 1,000.00 per truck per day
- Delivery of equipment, materials, and fixtures using 10-wheeler and up: Php 2,000.00 per truck per day
- Hauling of equipment and materials using 10-wheeler and up: Php 2,000.00 per truck per day
- Installation of wires and cables per street: Php 1,000.00
- Movie / TV / Commercial Shooting per day: Php 4,000.00
- Business fliers and sampler distribution per day: Php 1,000.00
- Government and religious fliers: exempted
- Other purposes not listed: Php 2,000.00
