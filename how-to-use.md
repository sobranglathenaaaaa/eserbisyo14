# How to Use eSerbisyo

Easy guide for residents, students, staff, and admin users.

Last updated: April 5, 2026

---

## 1) What is eSerbisyo?

eSerbisyo is an online barangay service system.

You can use it to:
- Register as a resident
- Request barangay documents
- Track your request status
- Receive updates and notifications
- Submit incident or blotter reports
- Join the queue
- View your request history
- Give feedback after service

---

## 2) Who uses this system?

- Resident: Requests services and tracks updates
- Student (Resident): Usually requests school-related documents
- Staff: Processes approved requests
- Admin: Reviews requests, approves/declines, manages users and announcements

If you are a student, you will mostly use the Resident steps in this guide.

---

## 3) Before You Start

Prepare these details first:
- Full name
- Birthdate
- Address
- Email address
- Phone number
- Any valid ID number
- Password (at least 8 characters)

Tip: Keep your phone nearby so you can check updates quickly.

---

## 4) Create a Resident Account (First Time Only)

1. Open the eSerbisyo website.
2. Click Register as resident.
3. Fill out the registration form:
   - Full name
   - Birthdate
   - Phone number
   - Address
   - Email address
   - ID number
   - Optional ID file name
   - Password and confirm password
4. Check the box for terms and privacy notice.
5. Click Create resident account.
6. You will be redirected to login.

Important:
- Your account is active immediately after registration.
- You do not need email verification to continue.

---

## 5) Log In

1. Go to the login page.
2. Enter your email and password.
3. Click Log In.
4. You will be sent to your dashboard based on your role.

If login fails:
- Check your email spelling
- Check your password
- Try again slowly (watch uppercase/lowercase)

---

## 6) Resident Guide (Main Student Guide)

### 6.1 Dashboard

Use the dashboard as your home page.

From here you can open:
- Document Requests
- Notifications
- Queue
- Census/Profile
- Request History
- Feedback

### 6.2 Request a Document

1. Open Document Requests.
2. Click Start a request (or similar button).
3. Choose the document type you need.
4. Enter purpose/notes clearly.
5. Submit your request.
6. Save your reference number if shown.

Write clear purpose examples:
- School requirement
- Scholarship requirement
- Financial assistance requirement

### 6.3 Understand Request Status

Your request can move through these statuses:

- pending: Submitted, waiting for admin review
- approved: Reviewed and accepted
- processing: Being prepared by staff
- completed: Ready to view/print/download
- declined: Not approved (check the reason)
- cancelled: Request was cancelled

What to do:
- If pending: wait and check notifications
- If declined: read reason, fix details, submit again
- If completed: open and print/download document

### 6.4 Cancel a Request

You can cancel only while status is pending.

You cannot cancel once status is processing.

### 6.5 Check Notifications

1. Open Notifications.
2. Read the latest update first.
3. Follow any action in the message.

You should check notifications daily when you have an active request.

### 6.6 View Request History

Use Request History to review your past transactions:
- Submitted requests
- Final statuses
- Completed documents
- Timeline of updates

### 6.7 Submit Incident or Blotter Report

1. Open Report an Incident / Blotter Reporting.
2. Enter complete details:
   - Title or concern
   - What happened
   - Location
   - Date
3. Submit report.
4. Track status updates.

Report statuses:
- pending
- under_review
- resolved

### 6.8 Update Profile/Census

1. Open Census or My Profile.
2. Review your details.
3. Update changed information.
4. Save.

Keep this updated to avoid delays in document processing.

### 6.9 Give Feedback

After a service is completed:
1. Open Request Feedback.
2. Rate the service (1 to 5).
3. Add optional comment.
4. Submit.

## 7) Student Quick Path (Fast Version)

If you only need a school document:

1. Register account
2. Log in
3. Open Document Requests
4. Choose School Requirement document
5. Submit request
6. Track status in Notifications
7. Open completed document and print/download

For most school-related requests, some document types are free.

---

## 8) Document Fees (Resident View)

Fees depend on document type and purpose.

Common examples:
- Barangay Certification - School Requirement: Free
- Barangay Certification - Indigency/Assistance: Free
- Barangay Certification - Employment: Php 100.00
- Police/NBI/Court Clearance purpose: Php 100.00
- Certificate of No Operation of Business: Php 200.00

Other categories also exist:
- Business Clearances
- Construction Clearances
- Delivery and Hauling Clearances
- Lupon-related certificates

Always check the exact fee shown in the app before finalizing.

## 9) Staff Guide

Use this section if your account is Staff.

Main pages:
- Dashboard
- Process Requests
- Medicines
- Notifications

Basic flow:
1. Open Process Requests.
2. Review approved requests.
3. Move request to processing when work starts.
4. Mark completed when done.
5. If request cannot proceed, decline with clear reason.

Rule:
- Decline actions must include a reason.

---

## 10) Admin Guide

Use this section if your account is Admin.

Main pages:
- Dashboard
- Document Requests
- Document Templates
- Incidents
- Announcements
- Notifications
- Queue
- Medicines
- Reports
- Users

### 10.1 Review Document Requests

1. Open Document Requests.
2. Check details carefully.
3. Approve if complete.
4. Decline with reason if incomplete.

Rule:
- Admin decline must include a reason.

### 10.2 Manage Templates

- Edit document wording
- Keep content clear and updated
- Save and verify preview

### 10.3 Manage Users

- Add staff or resident accounts
- Update user roles
- Soft delete and restore users

### 10.4 Monitor Operations

Use Dashboard and Reports to monitor:
- Total requests
- Pending requests
- Approved requests
- Completed requests
- Incident summaries
- Feedback trends

## 11) Troubleshooting (Simple)

Problem: I cannot log in
- Check email/password
- Make sure internet is stable
- Try again after 1 minute

Problem: My request is still pending
- This means waiting for review
- Check notifications regularly

Problem: My request was declined
- Open the decline reason
- Correct missing/incorrect details
- Submit a new request

Problem: I cannot cancel request
- Cancellation is only allowed while pending

Problem: I cannot find my completed document
- Check Request History and Notifications
- Confirm status is completed

---

## 12) Good Practices for Students and Residents

- Use your real and complete personal details
- Keep your phone number active for updates
- Read decline reasons carefully before resubmitting
- Keep screenshots/reference numbers for your records
- Do not share your password with others

---

## 13) Privacy and Safety Reminder

- Keep your account credentials private
- Log out on shared devices
- Report suspicious account activity to admin/staff immediately

---

## 14) Support Script (For Teachers or Barangay Staff)

If helping a student/resident, ask these in order:

1. Are you already registered?
2. Can you log in successfully?
3. Which document are you requesting?
4. What is your current request status?
5. Did you check notifications for latest update?
6. If declined, what reason was shown?

This usually solves most user issues quickly.

---

## 15) One-Page Summary

- Register once, then log in
- Submit request with complete details
- Track status and notifications
- Read decline reasons carefully
- Download/print when completed
- Give feedback after service

For students: the fastest route is Document Requests -> School Requirement -> Track Notifications -> Download when completed.
